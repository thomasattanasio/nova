# NOVA

> A small operating system built from scratch.

NOVA is an educational hobby operating system developed from scratch to explore how modern computer systems work at a low level.

The project focuses on understanding and implementing the fundamental components of an operating system, from the boot process and kernel initialization to memory management, processes, system calls, filesystems, and userspace.

## Project Goals

- Learn how an operating system works from the ground up.
- Explore low-level computer architecture and x86-64 systems.
- Build a modular and maintainable kernel.
- Develop the project incrementally with a strong focus on understanding each component.
- Keep the project open source and accessible for learning and experimentation.

## Target Platform

- **Architecture:** x86-64
- **Primary development environment:** Linux
- **Initial execution environment:** QEMU

## Languages

- **C** — primary implementation language
- **x86-64 Assembly** — low-level architecture-specific components

## Project Status

NOVA is currently in the early stages of development.

The project is being built incrementally, starting from the boot process and kernel foundation.
